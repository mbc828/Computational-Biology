# ADMET 规则模型交叉验证报告

日期：2026-08-08 ｜ 项目：SHXD-PJI ｜ 状态：✅ 计算交叉验证已完成

## 1. 目的

工作簿 `ADMET_Tox` 表与 `PhysChem_ADMET` 风险概率列此前为**自建 sigmoid/规则模型的未验证输出**（审计标记 🟡，不能作为验证平台结果引用）。本次用独立的第二平台 **ADMETlab 2.0**（scbdd.com，端到端不同训练集与算法）对 16 个成分做全端点复测，检验内部模型方向是否可信，并定位必须靠湿实验裁决的分歧点。

平台选择说明：admetSAR 2.0 接口返回空体不可用；pkCSM / ADMETlab 3.0 为 JS 应用无法脚本化；ADMETlab 2.0 经 csrf 流程跑通，16/16 成分全部返回完整结果（原始 HTML 存 `results_al2/`）。

## 2. 数据量

- 16 成分 × 50 端点 = **800 条 ADMETlab 2.0 预测**（`admetlab2_master.csv`）
- 内部模型可映射端点 11 个方向对 × 16 成分 = **176 组方向对照** + PPB 数值相关
- 逐条对照表：`xval_comparison.csv`

判定规则：内部概率 ≥0.5 判阳性；ADMETlab2 `+/++/+++` 判阳性、`-/--/---` 判阴性；HIA 按平台定义（HIA+ = 吸收 <30%）。

## 3. 总体结果

**总方向一致率 91/176 = 51.7%** —— 结论：内部规则模型不能单独作为安全性论据，但交叉验证后每个端点现在都有了"可信/存疑"的明确归类。

### 3.1 一致良好的端点（内部模型这些列可直接引用，注明双平台一致）

| 端点对 | 一致率 | 说明 |
|---|---|---|
| Hepatotoxicity ↔ H-HT | **16/16 (100%)** | 两平台均判全部 16 成分人肝毒性阴性 |
| GI absorption ↔ HIA | 13/16 (81%) | 分歧仅 Baicalin/Wogonoside（内部1% vs AL2判吸收≥30%）与 Magnoflorine |
| CYP2C19 ↔ CYP2C19 inhibitor | 12/16 (75%) | |
| hERG ↔ hERG Blockers | 11/16 (69%) | 11 个黄酮/蒽醌一致判阴性 |

### 3.2 显著分歧的端点（内部模型这些列**不可引用**，需实验裁决）

| 端点对 | 一致率 | 分歧要点与文献方向 |
|---|---|---|
| DILI ↔ DILI | 1/16 (6%) | AL2 DILI 模型判 15/16 阳性（多为 +++），但其自身 H-HT 模型判全阴 → **平台内部矛盾**，属模型噪声高区，只能实验定 |
| P-gp ↔ Pgp-inhibitor | 1/16 (6%) | 内部规则判 16/16 全抑制（规则过宽），AL2 判 15/16 阴性；文献中黄芩苷/小檗碱为 P-gp 调节剂 → 内部列明显不可靠 |
| CYP1A2 ↔ inhibitor | 6/16 (38%) | AL2 判 5 个黄酮（Baicalein/Wogonin/Oroxylin A/Apigenin/Chrysin）+++ 抑制——**与已知文献一致**（黄酮类确为 CYP1A2 抑制剂），内部"全 Low"大概率漏报 |
| Ames ↔ AMES | 8/16 (50%) | AL2 判 4 个蒽醌（Emodin ++、Rhein +++、Aloe-emodin ++、Chrysophanol ++）Ames 阳性——**与文献一致**（蒽醌类已知致突变性），内部"全 Low"漏报 |
| CYP2C9 / CYP2D6 / CYP3A4 | 44–50% | 同为黄酮类抑制信号被内部漏报 |
| PPB（数值） | Spearman ρ = **−0.40** | 系统偏移：AL2 均值 91.3% vs 内部 56.4%；内部数值不可作绝对值引用 |

### 3.3 单成分重点

- **Berberine hERG**：内部 0.73(High) ↔ AL2 `--`（非阻断）——两平台直接冲突；文献有小檗碱 hERG 阻断报道（μM 级）。**这是全文唯一的高风险未决信号，必须 patch-clamp 裁决。**
- **蒽醌 4 成分（Emodin/Rhein/Aloe-emodin/Chrysophanol）**：AL2 Ames 阳性 + 致癌性 +/++（Chrysophanol +++），且 DILI +++——大黄蒽醌安全性是审稿人必问点，内部"全 Low"结论**不成立**，必须改写成"存在文献报道的致突变/肝毒风险，需 Ames 实验确认"。
- **生物碱（Berberine/Coptisine）**：AL2 新增 Carcinogencity +++、BBB +++（Berberine/Palmatine）——BBB 对 PJI 局部用药反而是穿组织能力证据，可作为全身暴露低的佐证讨论。

### 3.4 AL2 新增信号（内部模型完全未覆盖的端点）

- Carcinogencity 阳性：Berberine(+++)、Coptisine(+++)、Chrysophanol(+++)、Aloe-emodin(++)、Rhein(+)
- Respiratory Toxicity 阳性 6 个（生物碱类为主）
- Skin Sensitization 13/16 阳性（该端点假阳性率高，仅作提示）
- NR-AhR / SR-p53 近乎全阳性——黄酮类混杂性已知，作假设生成，不入结论
- Rat Oral Acute Toxicity：**16/16 全部低毒**（可作为"急性毒性风险低"的双平台一致论据写入手稿）

4. PPB 数值列建议整列删除或标注"仅用于成分间相对比较"（与 AL2 无相关性 ρ=−0.40）。

## 5. 湿实验验证方案（计算侧已做完，以下为实验侧待办）

### 第一梯队：自有平台可做，1–2 周，成本低 ✅ 现在就能做
**CCK-8 细胞活力**（验证内部"Macrophage viability"列 + 为后续功能实验定剂量）
- 细胞：THP-1 巨噬细胞（即现有 qPCR 平台）
- 成分：6 个 Priority-1（Baicalein、Berberine、Wogonin、Baicalin、Emodin、Wogonoside）
- 浓度梯度 0.1–100 μM，24h/48h 两个时间点，3 复孔
- 产出：IC10/IC20（后续抗炎实验用 ≤IC10 剂量，直接回应"剂量合理性"审稿点）

### 第二梯队：试剂盒/外包，4–8 周
1. **Ames 试验**（TA98/TA100 ± S9）：4 个蒽醌 + Berberine 对照 → 裁决最大分歧点（AL2/文献阳性 vs 内部阴性）。外包 CRO 约每成分几千元
2. **hERG 膜片钳**（自动化 APC 外包，或 hERG 荧光通量试剂盒）：Berberine、Palmatine、Jatrorrhizine、Coptisine、Magnoflorine（内部判阳性的 5 个）→ 裁决 hERG 冲突
3. **CYP1A2 抑制**（重组酶+探针底物试剂盒）：5 个黄酮 → 确认 AL2/文献一致信号

### 第三梯队：结论需要时再补
- DILI：HepG2 glu/gal 线粒体毒性 + 小鼠治疗剂量 ALT/AST/CRE/BUN
- P-gp：Caco-2 双向转运（仅当手稿保留 P-gp 论述时）
